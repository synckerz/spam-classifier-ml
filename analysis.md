# SMS Spam Classification – Analysis

The aim of this project was to develop a simple AI model that can classify SMS messages as spam or not spam. I used Python and the Scikit-learn library to implement a Multinomial Naive Bayes classifier. The model was trained using the SMS Spam Collection dataset from the UCI Machine Learning Repository, which contains 5,572 messages.

The dataset was divided into 80% training data and 20% testing data. This produced 4,457 training messages and 1,115 testing messages. CountVectorizer was used to convert the text messages into numerical word-count features before training the model. The training and prediction steps were carried out using a Scikit-learn Pipeline.

The model achieved an accuracy of 98.74%, precision of 98.56% and recall of 91.95%. These results show that the model performed well on the test dataset. The confusion matrix showed 964 correctly identified legitimate messages and 137 correctly identified spam messages. However, 12 spam messages were incorrectly classified as legitimate, while 2 legitimate messages were classified as spam. Therefore, the model made 14 incorrect predictions out of 1,115 test messages. The results indicate strong overall performance, but recall shows that some spam messages were still missed.

There are also ethical considerations when using this type of AI model. The dataset contains examples of personal communication, so privacy and responsible data use are important. Although the dataset is publicly available, this does not mean that message data should be used without considering privacy. In a real messaging service, users should be informed about how their messages are processed and protected.

The model also has limitations. The dataset may not represent all users, languages or communication styles. As a result, performance may be lower for messages that differ from the examples used during training. The classifier may also struggle with new spam techniques that were not included in the dataset. A false positive could cause a legitimate message to be treated as spam, while a false negative could allow an unwanted message through.

Overall, the project demonstrated how machine learning can be used for SMS spam detection. Although the model achieved good results on this test split, its predictions should not be treated as completely reliable. Further testing with newer and more diverse messages would help assess how well it performs in real-world use.
